# Little Oaks — Director Dashboard

Operational dashboard surface for the Headmistress and authorized school leadership.

## Live domains

- Student population
- Admissions
- Enrollment and class placement
- Attendance
- Fees and billing
- Parents and guardians
- Academic operations
- Operational alerts

## Dashboard principles

- Authenticated access
- Organization-scoped data
- Permission-controlled visibility
- Live API-backed metrics
- Mobile-first operational interface
- Director-level decision support
