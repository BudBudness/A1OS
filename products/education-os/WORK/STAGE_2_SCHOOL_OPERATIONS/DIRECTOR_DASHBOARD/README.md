# Little Oaks — Director Dashboard

## Purpose
Executive operational intelligence surface for Little Oaks Montessori Nursery & Kindergarten.

## Dashboard domains
- Student population
- Admissions pipeline
- Enrollment and class placement
- Attendance health
- Fees and collections
- Parent / guardian coverage
- Staff / HR overview
- Academic year and period status
- Operational alerts

## Data sources
- students
- admissions
- enrollments
- attendance
- student_fees
- fee_payments
- parents_guardians
- student_guardians
- staff
- academic_years
- academic_periods
- class_levels

## Design principles
- Authenticated
- Organization-scoped
- Permission-aware
- Read-only executive aggregation
- API-first
- Audit-ready
- Mobile-compatible
- Suitable for daily director operations

## Acceptance standard
- Dashboard API contract defined
- Existing operational domains mapped
- Python syntax passes
- GitHub delivery passes
- Production service health passes
