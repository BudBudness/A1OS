# A1OS Vertical Template Catalog

This catalog defines reusable product vertical recipes for the A1OS factory.

A template is a product composition contract, not a generated customer
application.

## Architecture

Template
→ capability selection
→ A1OS platform contracts
→ vertical source generation
→ validation
→ product E2E acceptance
→ deployment

## Safety

The catalog definition itself does not generate products, modify existing
verticals, execute production workloads, access production databases, or
handle secrets.
