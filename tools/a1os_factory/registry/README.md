# A1OS Factory Product Registry Command Center v2.1

Purpose:

Central control layer for all A1OS products.

Usage:

python3 registry_engine.py


Generated:

factory_registry/
└── PRODUCT_REGISTRY.json


Tracks:

- Product identity
- Domain profile
- Factory version
- Lifecycle status
- Product layers
- Capability map


Supported products:

- Education OS
- NGO OS
- Legal OS
- Media OS
- Finance OS
- Business OS
