# A1OS Factory v1.3 Autonomous Product Composer

Usage:

python3 product_composer.py <product-name> <profile>

Examples:

python3 product_composer.py school-os education

python3 product_composer.py pyong-media media

python3 product_composer.py finance-core finance

Output:

products/
└── product-name/
    ├── core/
    ├── intelligence/
    ├── api/
    ├── web/
    ├── deployments/
    ├── docs/
    └── A1OS_MANIFEST.json
