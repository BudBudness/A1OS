# School Management Frontend

Frontend implementation contract for A1OS Core/Platform.

This directory contains presentation, workflow, form and client-state code only. Business authorization, tenancy, persistence and execution remain platform-owned.

- `users`
- `roles`

- `fees`
- `notifications`
- `audit`
- `site_content`
