# A1OS Platform Contract

A1OS is a multi-organization business operating platform.

## Non-negotiable architecture

**Folders over agents.**

Deterministic modules, workflows, policies and services own application behavior.

AI may interpret intent and provide recommendations, but does not become the authority for business rules, permissions, financial calculations, infrastructure state, destructive execution or security policy.

## Authority

The platform owner has a dedicated Command Center with platform-wide visibility and control.

Organizations receive configurable products and capabilities appropriate to their business.

## Autonomy

A1OS may autonomously execute policy-approved operations.

Consequential operations require the configured approval gate.

Every execution must be:

1. authorized
2. validated
3. executed
4. verified
5. audited

## Product model

Verticals are configurable products, not independent copies of the platform.

Organization configuration controls:

- enabled capabilities
- branding
- terminology
- workflows
- permissions
- business rules
- integrations
- interface configuration

## Terminal

The managed terminal is a first-class platform resource.

Terminal operations must use explicit workflows and policies rather than unrestricted AI-generated shell execution.

## Production rule

No feature is considered production-ready merely because code compiles.

Production certification requires static validation, tests, migration validation, deployment validation, service health, API health, public endpoint validation and audit evidence.
